Forecasts GTA VI's launch-day Twitch concurrent viewers hour by hour (hours 2–24, five quantiles each) from the first hour's print, by pooling the release-day curves of past comparable launches with a Gaussian kernel on log opening size. Leave-one-out cross-validation over the kit's 37 comparables: mean pinball loss 0.40 vs the persistence baseline's 0.93.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
